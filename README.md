# Blog SPA (Vue)

An early project (2021): a blog front end with a home page, a paginated post list, single-post and author views, a contact page and an add-post form, backed by a REST API.

## Tech stack
Vue 2 · Vuex · Vue Router · axios / vue-resource · Tailwind pagination · Font Awesome

## Run
```bash
npm install && npm run dev
```
